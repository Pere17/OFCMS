System Architecture

The MVC request lifecycle: every request passes through role-based middleware before reaching a controller, which reads and writes through Eloquent models to the database and renders a Blade view in response.

flowchart LR
    U["Browser
(Complainant / Admin / Super Admin)"] -->|HTTP request| R["Routes
web.php"]
    R --> M{"RoleMiddleware
role + is_active check"}
    M -->|denied| F["403 Forbidden"]
    M -->|allowed| C["Controller
Complainant / Admin / SuperAdmin / Category"]
    C --> EM["Eloquent Models
User · Complaint · Category · Response · Feedback"]
    EM --> DB[("MySQL / MariaDB")]
    C --> N["Notification System
database + mail channel"]
    C --> V["Blade View"]
    V -->|HTML response| U
    N -.-> U

Sequence Diagram — Complaint Submission & Resolution

The end-to-end interaction between a Complainant, an Administrator, and the system, from submission through to resolution and notification.

sequenceDiagram
    actor C as Complainant
    participant CC as ComplainantController
    participant M as Complaint Model
    participant N as Notification System
    actor A as Administrator
    participant AC as AdminController

    C->>CC: Submit complaint form
    CC->>CC: Validate input
    CC->>M: Complaint::create()
    M->>M: Auto-generate reference_number
    M-->>CC: Complaint saved (status = pending)
    CC->>N: notify(ComplaintSubmitted)
    N-->>A: In-app + email notification
    CC-->>C: Redirect with reference number

    A->>AC: Open complaint, write response
    AC->>M: responses()->create()
    AC->>M: update(status, resolved_at)
    AC->>N: notify(ComplaintResolved)
    N-->>C: In-app + email notification
    AC-->>A: Confirmation message

Activity Diagram — Complaint Handling

The activity flow from submission through validation, review, and either resolution or continued investigation.

flowchart TD
    Start(["Start"]) --> Submit["Complainant fills complaint form"]
    Submit --> Validate{"Valid input?"}
    Validate -- No --> ShowErrors["Show validation errors"]
    ShowErrors --> Submit
    Validate -- Yes --> Save["Save complaint & generate reference number"]
    Save --> NotifyAdmin["Notify Administrators"]
    NotifyAdmin --> Review["Administrator reviews complaint"]
    Review --> SetStatus["Update status / priority / assignee"]
    SetStatus --> Respond["Administrator writes a response"]
    Respond --> Resolved{"Marked resolved?"}
    Resolved -- No --> NotifyUpdate["Notify complainant of status update"]
    NotifyUpdate --> Review
    Resolved -- Yes --> Stamp["Set resolved_at timestamp"]
    Stamp --> NotifyResolved["Notify complainant — resolved"]
    NotifyResolved --> End(["End"])
